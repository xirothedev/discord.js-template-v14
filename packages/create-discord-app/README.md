# @xirothedev/create-discord-app

Bun-first project generator for the `discord.js-template-v14` template.

## Usage

```sh
bunx @xirothedev/create-discord-app my-bot
```

## Options

```txt
--yes
--no-git
--skip-install
--token <value>
--client-id <value>
--owner <value>
--developers <value>
--prefix <value>
--database-url <value>
--redis-url <value>
```
